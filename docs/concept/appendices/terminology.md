## Definitions

**Future-affecting write:** any persistent object that can influence later agent behavior.

**Governed promotion:** the process by which a proposed future-affecting write becomes eligible to influence later runs.

**Claim:** typed statement about requirements, repo facts, assumptions, design decisions, risks, or test oracles.

**Artifact:** versioned reusable object that can change future behavior or projection.

**Projection:** rendering of trusted state into an agent-consumable surface such as prompt text, `AGENTS.md`, `CLAUDE.md`, or skill markdown.

**Activation:** runtime decision to include a claim/artifact/projection in a run.

**Demotion:** removal or reduction of future influence because of staleness, regression, or review.
