The stage plan should be brutally sequential.

**Stage A — interception only**

Replace direct trusted writes in Hermes self-improvement paths with proposals.

Success condition:
- every future-affecting write path identified in Hermes routes through proposal creation. **`source-verified` need, `inferred` implementation target**

Failure cutoff:
- if a significant class of future-affecting writes still bypasses Nova, stop and shrink scope.

**Stage B — one artifact family only**

Promote only **project instructions** or **skills**, not both.

Recommended starting family:
- **skills**, because Hermes already has explicit skill objects and write tooling. **`inferred`**

Success condition:
- proposals are readable, evidence-linked, and reviewable.
- active artifacts are injected into later runs through one stable path.

Failure cutoff:
- if proposals collapse into verbose summaries that reviewers cannot evaluate quickly, shrink payload or stop.

**Stage C — evaluator-gated promotion**

Add automatic checks for one artifact family:
- syntax/shape validation
- scope validation
- replay smoke test against one held-out task set

Failure cutoff:
- if evaluator acceptance has high false-positive regression cost, revert to human-only gating.

**Stage D — blame and demotion**

Log activation records and tie regressions back to active artifacts.

Failure cutoff:
- if regression attribution is too noisy to support demotion, the thesis is only partially proven; do not expand artifact types.
